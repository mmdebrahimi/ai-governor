1. **Run the decision-elicitation probe (anchor 5).** One real operational decision - e.g. "which parcels
   do we plant next season, with what?" - run by hand through decision -> statistic -> observation ->
   instrument. Two checks: did it surface a data need you hadn't thought of (tests R1/A1), and is the
   resulting question-list one you'd actually answer (tests A2)? Costs an hour, needs no code, and is
   UNAFFECTED by all three ratified answers. It can invalidate the two weakest assumptions in the project.
2. **Then re-decompose.** The current decomposition points at a Mars colony. Under the ratified answers
   the family shape is roughly: neutral core (exists) -> land pack -> gap-report + governance layer
   (coupled) -> ontology induction -> interrogation loop.
3. **Do not seed families or write code before (1).** Scaffolding before validating is the error this
   session has now warned about twice.
4. **Solve the unanswered-question problem explicitly** before the interrogation loop is built. Candidates:
   ask only the k highest-value questions ranked by decision-sensitivity; let an unanswered field degrade
   downstream CONFIDENCE rather than block; or make the question itself the deliverable.
